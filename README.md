# 🏡 우리 가족 기록장

우리집의 포근한 하루를 함께 기록하는 가족 대시보드입니다. 설치 없이 브라우저로 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요(PWA).

- 배포 주소(예정): `https://karisma1690-coder.github.io/family-dashboard/`
- 작업 위치: `work/family-dashboard/`
- 구성원: 아빠(성영) · 엄마(수나) · 윤슬 · 노을

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조(헤더·날씨·가족 현황·도장판·미션·공부·할 일·채팅·모달) |
| `styles.css` | 크림/파스텔 디자인, 모바일 우선 반응형, 애니메이션 |
| `app.js` | 모든 로직(저장·계산·타이머·효과), 외부 라이브러리 없음 |
| `manifest.webmanifest` | PWA 매니페스트(홈 화면 추가, 앱 이름·아이콘) |
| `sw.js` | 오프라인 캐시(HTTPS에서만 등록) |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | 앱 아이콘 |
| `test_app.py`, `test_app2.py` | 브라우저 자동 검증 스크립트(Playwright) |

## 기능

1. **상단 헤더 & 날씨** — 오늘 날짜·요일, 인사말, 울산 실시간 날씨/미세먼지(Open-Meteo, 키 불필요). 실패하면 마지막으로 받은 값을 `저장된 값`으로 보여 주는 오프라인 폴백.
2. **가족 현황** — 4명 아바타(SVG), 오늘 완료 별 수, 돼지저금통 누적 금액. 적립할 때 코인이 날아가는 애니메이션.
3. **주간 달성률 · 용돈(90% 규칙)** — 월~일 완료 항목 기준 달성률 게이지, 90% 목표 표시, 남은 개수 안내. 90%를 넘으면 `🎉 목표 90% 달성!` 배지와 `💰 용돈 저금통에 넣기` 버튼이 열리고, 한 주에 한 번만 받을 수 있어요. 금액은 설정에서 윤슬·노을 각각 변경(기본 5,000원).
4. **도장판** — 윤슬/노을 전환, 월~일 주간 도장, 🔥 연속 일수, 이번 달 도장 개수, `도장판 달력 보기` 모달.
5. **오늘의 가족 미션** — 16가지 미션 풀에서 뽑기, `다 같이 했어요`로 함께 N번 카운트 + 축하 효과, `다른 미션 뽑기`.
6. **공부 플랜** — 구성원별 체크리스트(항목별 100·50·0원 설정), 체크 즉시 저금통 적립, `N/M 완료` 진행률, 고정 항목 관리, 공부 추가/수정/삭제.
7. **공부 타이머** — `남은 시간`/`재는 시간` 모드, 10·20·30분·직접 입력, 시작/일시정지/초기화. 시간이 끝나면 Web Audio 알림음 + 진동 + `공부 완료! 태블릿 정리할 시간이에요` 알람 모달.
8. **오늘 할 일** — 4명 각자 추가·수정·삭제·체크. 한 사람이 모두 끝내면 🙌 하이파이브 배지와 축하 효과.
9. **우리집 한마디** — 보낸 사람을 고르고 짧은 응원/메모 남기기(최근 40개 표시, 200개 보관).
10. **저장 & 설정** — 모든 기록은 브라우저 `localStorage`에만 저장, 설정에서 용돈 금액 변경, JSON 백업/불러오기, 전체 초기화.

## GitHub Pages 배포 방법

`@karisma1690-coder` 계정에 `family-dashboard` 공개 저장소를 만들고 `main` 브랜치 루트에서 Pages를 켭니다.

```bash
cd work/family-dashboard
git init -b main
git add .
git commit -m "우리 가족 기록장 대시보드"
gh repo create karisma1690-coder/family-dashboard --public --source=. --push
# Pages 켜기 (main / 루트)
gh api -X POST repos/karisma1690-coder/family-dashboard/pages \
  -f 'source[branch]=main' -f 'source[path]=/'
```

잠시 뒤 `https://karisma1690-coder.github.io/family-dashboard/` 에서 열립니다.
(브라우저 설정에서 GitHub 앱의 저장소 생성 권한이 필요할 수 있어요.)
