# 🏡 우리 가족 기록장

우리집의 포근한 하루를 함께 기록하는 가족 대시보드입니다. 설치 없이 브라우저로 열고, 홈 화면에 추가하면 앱처럼 쓸 수 있어요(PWA).

- 배포 주소: `https://karisma1690-coder.github.io/family-dashboard/` (2026-11-16 배포 완료)
- 저장소: `https://github.com/karisma1690-coder/family-dashboard` (공개, `main` / 루트)
- 작업 위치: `work/family-dashboard/`
- 구성원: 아빠(성영) · 엄마(수나) · 윤슬 · 노을

## 기능

1. **상단 헤더 & 날씨** — 오늘 날짜·요일, 인사말, 울산 실시간 날씨/미세먼지(Open-Meteo, 키 불필요). 실패하면 마지막으로 받은 값을 `저장된 값`으로 보여 주는 오프라인 폴백.
2. **가족 현황** — 4명 아바타(SVG), 오늘 완료 별 수, 돼지저금통 누적 금액. 적립할 때 코인이 날아가는 애니메이션.
3. **🕺 아빠 댄스** — 가족 현황의 아빠(성영) 행을 누르면 고양이 아바타가 4.5초 동안 좌우로 흔들리며 점프 춤을 춰요(다시 누르면 춤 연장). 음표·반짝이가 날아다니고 말풍선(`아빠 신났다! 🕺`, `윤슬·노을 하이파이브! 🙌` 등)이 뜨고, Web Audio로 짧은 8비트 멜로디가 나옵니다. 카드 우측 🔊 버튼으로 효과음 끄기/켜기(설정 유지). `💼 일하는 중 / 🏠 집 도착 / 🏋️ 운동 중 / 🕺 춤추는 중` 상태 칩을 누르면 상태가 바뀌면서 바로 춤을 춰요(새로고침해도 유지). 엄마·윤슬·노을 행을 누르면 각자 반짝이 + 점프로 대답해요.
4. **🎵 우리집 주크박스** — 추천 동요 6곡(아기상어·곰 세 마리·작은 별·뽀로로 동요·바나나 차차·신나는 율동동요)을 누르면 대시보드 안 임베드 플레이어로 바로 재생. 검색창에 제목·가수를 적고 `🔍 검색 & 듣기`를 누르면 추천곡과 겹치면 바로 재생, 그 밖의 곡은 `🎵 유튜브 뮤직에서 바로 틀기`(music.youtube.com 검색/영상)와 `▶ 유튜브에서 검색 결과 보기`로 한 번에 이어져요. 유튜브 영상 링크(또는 영상 ID)를 붙여 넣으면 대시보드 안에서 재생됩니다. 최근 들은 노래 6개를 칩으로 남겨 두고 한 번에 다시 틀 수 있어요(`localStorage` 저장).
5. **주간 달성률 · 용돈(90% 규칙)** — 월~일 완료 항목 기준 달성률 게이지, 90% 목표 표시, 남은 개수 안내. 90%를 넘으면 `🎉 목표 90% 달성!` 배지와 `💰 용돈 저금통에 넣기` 버튼이 열리고, 한 주에 한 번만 받을 수 있어요. 금액은 설정에서 윤슬·노을 각각 변경(기본 5,000원).
6. **도장판** — 윤슬/노을 전환, 월~일 주간 도장, 🔥 연속 일수, 이번 달 도장 개수, `도장판 달력 보기` 모달.
7. **오늘의 가족 미션** — 16가지 미션 풀에서 뽑기, `다 같이 했어요`로 함께 N번 카운트 + 축하 효과, `다른 미션 뽑기`.
8. **공부 플랜** — 구성원별 체크리스트(항목별 100·50·0원 설정), 체크 즉시 저금통 적립, `N/M 완료` 진행률, 고정 항목 관리, 공부 추가/수정/삭제.
9. **공부 타이머** — `남은 시간`/`재는 시간` 모드, 10·20·30분·직접 입력, 시작/일시정지/초기화. 시간이 끝나면 Web Audio 알림음 + 진동 + `공부 완료! 태블릿 정리할 시간이에요` 알람 모달.
10. **오늘 할 일** — 4명 각자 추가·수정·삭제·체크. 한 사람이 모두 끝내면 🙌 하이파이브 배지와 축하 효과.
11. **우리집 한마디** — 보낸 사람을 고르고 짧은 응원/메모 남기기(최근 40개 표시, 200개 보관).
12. **저장 & 설정** — 모든 기록은 브라우저 `localStorage`에만 저장, 설정에서 용돈 금액 변경, JSON 백업/불러오기, 전체 초기화.
13. **✈️ 우리 가족 여행 보드(세계 지도 · 사진 · 일정)** — 기록장의 `여행 보드 열기` 카드나 태블릿 캘린더 보드의 `✈️ 여행` 탭으로 열어요. ① 여행 도감 요약(🚩 다녀온 곳 N곳 · ⭐ 가고 싶은 곳 N곳) ② **세계 지도 ↔ 한국 지도 전환** — 기본은 도트 일러스트 세계 지도(아시아·유럽, 아프리카, 북미, 남미, 오세아니아 실루엣)에 한국·일본·동아시아·동남아·유럽·북미·남미·오세아니아·중동·아프리카 권역 핀, `🗺️ 한국 지도`로 바꾸면 기존 9개 국내 권역(서울·경기, 강원, 충청, 경주·대구, 울산, 부산, 여수·전라, 제주, 해외·기타) 핀이 보여요. 세계 지도의 `한국` 핀은 국내 여행을 한 자리에 묶어 개수 배지로 보여 줘요. ③ 모든 핀은 🚩 다녀온 곳(초록) / ⭐ 가고 싶은 곳(노랑) / 📍 미방문(회색) + 개수 배지, 누르면 그 지역 기록만 모아 보기(`＋ 이 지역에 추가` 포함) ④ 다녀온 곳·가고 싶은 곳 2단 목록(권역·시기·기간·메모·일정·사진 썸네일, 수정·삭제, `다녀왔어요 🚩` 원클릭 전환) ⑤ **사진 기록** — 여행지 모달에서 사진을 넣으면 브라우저 canvas로 긴 변 640px·JPEG 0.72로 자동 압축해 저장(여행당 최대 3장). 카드에 썸네일이 붙고 누르면 크게 보기(라이트박스)로 이전/다음·개별 삭제 ⑥ **일정 기록** — 시작일·종료일과 일차별 일정 메모(한 줄에 하나, `＋ N일차 추가`), 카드에 일정 미리보기(3줄 + 더 보기 토글). 시작일이 있으면 `📅 캘린더 보드에도 넣기`로 태블릿 캘린더에 `✈️ OO 여행` 일정이 기간째 생기고, 수정·해제·삭제하면 캘린더 일정도 함께 바뀌어요 ⑦ 여행 기록·사진·일정은 이 기기 `localStorage`에만 저장되고, 설정의 JSON 백업과 캘린더 보드의 일정 JSON 백업(⬇️⬆️)에 함께 담겨 왕복 복원돼요.

## GitHub Pages 배포 상태

- 저장소: `karisma1690-coder/family-dashboard` (공개)
- Pages: `main` 브랜치 / `/ (root)` — Deploy from a branch, HTTPS 강제 켜짐
- 사이트: `https://karisma1690-coder.github.io/family-dashboard/`

배포 파일은 저장소 루트에 있는 `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, 아이콘, `.nojekyll` 입니다. `main`에 푸시하면 1~2분 안에 자동으로 다시 빌드됩니다.

> 당시 `gh api -X POST repos/.../pages`는 GitHub 앱 토큰에 Pages 권한이 없어 403(`Resource not accessible by integration`)이 났고, 저장소 Settings → Pages 화면에서 직접 켰습니다. 이후 갱신은 푸시만으로 됩니다.
